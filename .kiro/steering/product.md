# Product Overview

http-load-test is a comprehensive HTTP load testing tool that combines a high-performance Go engine with a modern web interface. The tool allows developers to perform endpoint load testing with configurable parameters like request rates, concurrency, and custom success validation.

## Key Features

- **Dual Architecture**: Go backend for performance-critical load testing execution, Node.js/JavaScript API for ease of use
- **Real-time Monitoring**: Web dashboard with live metrics, charts, and WebSocket-based updates
- **Flexible Configuration**: Support for custom headers, request bodies, HTTP methods, and JavaScript-based success validation
- **Rate Limiting**: Configurable requests per second with concurrent request control
- **Cross-platform**: Builds for Linux, macOS, and Windows with automated binary distribution
- **NPM Package**: Installable via npm/yarn with programmatic API access

## Target Users

- Backend developers testing API performance
- DevOps engineers integrating load testing into CI/CD pipelines
- QA teams validating system performance under load
